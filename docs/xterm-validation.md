- 自动协议回复不计入用户输入；旧流请求不能操作新流。

## 浅色主题与上一版小窗交互回归修复

用户反馈小窗顶部标签/按钮消失后，在运行中的 DSH 浅色页面确认：宿主使用
`--dsw-alias-label-primary` / `--dsw-alias-bg-layer-1`，而旧面板读取未定义的
`--color-text` / `--color-surface`，最终将接近黑色的继承文字显示在深色背景上。

- 面板改用宿主的成对前景/背景主题变量，缺省颜色也成对设置；历史预览背景同步适配。
- 恢复原有 `^C` / `^D` / `^Z` 控制按钮，使用按钮也正确计入用户输入。
- 浏览器 fixture 改为复现宿主的浅色主题，并检查浅色、深色及无主题变量三种情况下
  标签和操作按钮的文字对比度至少为 4.5:1。
- 实测旧版无 `.meta.json` 的日志、展开/收起预览、多选两条记录、附加用户说明并引用。
- 实测退出后预选/展开刚结束记录、显式分析、直接退出不分析，以及活动终端不能静默丢弃。
- 新浏览器回归全部通过；既有真实 PTY、vim、连接及生命周期测试继续通过。
